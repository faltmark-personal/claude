Music account

Official mode setup

  1. In Google Cloud Console create a project, enable YouTube Data API v3, configure the OAuth consent screen (External, add yourself as a test user).
  2. Create an OAuth client ID of type Web application with redirect URI , then download its JSON.
  3. Upload it here, then connect.

ytmusicapi setup

  1. Install the extra: pip install '.[ytmusic]'
  2. Open music.youtube.com signed in, open developer tools → Network, click any request to browse, and copy its request headers (Firefox: "Copy request headers"; Chrome: view source of Request Headers).
  3. Paste them here. They act like a password. They're stored only in your local data folder.

Getting the playlist onto your Fenix 8 Pro

This app creates the playlist in your YouTube Music account. Downloading it to the watch happens in Garmin's YouTube Music watch app. Nothing here can push music to the watch directly.

  1. Once: install YouTube Music from the Connect IQ Store on your phone and sign in on the watch with the code it shows. Use your personal Google account (Brand Accounts aren't supported). This needs YouTube Music Premium, which you have.
  2. Save the playlist from the Playlist tab. With "refill the same playlist" on, it keeps the same name and ID every time.
  3. On the watch, open the YouTube Music app → Add music / library → pick the playlist (only needed the first time if you reuse it).
  4. Put the watch on Wi-Fi (on its charger is easiest) and let it sync. Downloads only happen over Wi-Fi.
  5. Before the run: pair your Bluetooth headphones, open the music controls, choose the playlist and turn shuffle off so songs play in workout order.
  6. Start the music and the workout at the same moment. If you pause the workout, pause the music too, or the two clocks drift apart.

Things to know

  • Songs play whole. There's no trimming, crossfading or timed switching on the watch, so music changes land near boundaries (see the Timing table).
  • Very short intervals are grouped together and share one tempo.
  • Distance-based steps are converted to time at the planned pace. If you run faster or slower, the music drifts.
  • The playlist is prepared before the run. It doesn't react to your live heart rate.
  • Check the playlist order on the watch the first time. If the watch reorders it, tell me and we'll work around it.

If saving doesn't work

Use Export CSV. It has a YouTube Music link for every song, so you can build the playlist by hand in the app and then download it the same way.
